========================================================
  ДЖАРВИС — персональный AI-агент
  Как запустить (30 секунд)
========================================================

В архиве два установщика — оба рабочие, выберите любой:

  JARVIS-Live.command  — ПОСТОЯННЫЙ. Скачайте один раз,
                         дальше он сам скачивает самую свежую
                         версию с GitHub при каждом запуске.
                         Именно его стоит оставить на рабочем
                         столе: он никогда не устаревает.

  JARVIS.command       — ТРАДИЦИОННЫЙ. Вся программа зашита
                         внутри файла, работает даже без
                         интернета. Тоже умеет обновляться
                         с GitHub, но запасная копия в нём
                         не стареет только вместе с самим файлом.

1. Распакуйте архив (двойной клик по zip) и дважды кликните
   по выбранному файлу .command.

2. Откроется чёрное окно Терминала. Подождите 10-20 секунд.
   Джарвис установится и сам откроется в браузере.

3. Чёрное окно можно закрыть — Джарвис продолжит работать.

На рабочем столе появится ярлык «Джарвис» — дальше открывайте
агента им. Повторный запуск = проверка обновлений + открытие,
чаты и ключи не теряются (они хранятся отдельно, в ~/JARVIS).

Постоянная ссылка на самый свежий установщик (скачать один раз
и пользоваться всегда):

  https://github.com/monshepiano/monshe/raw/installer/JARVIS.zip

Внутри — JARVIS-Live.command (постоянный установщик) и этот
файл инструкций. Скачанный один раз JARVIS-Live.command больше
никогда не устаревает: актуальный код он берёт с GitHub сам.


--------------------------------------------------------
  ЕСЛИ macOS НЕ ДАЁТ ОТКРЫТЬ
--------------------------------------------------------

Появилось окно «Не удалось открыть, неизвестный разработчик»?
Это обычная защита для файлов из интернета. Сделайте так:

  Способ 1 (самый простой):
    Кликните по файлу ПРАВОЙ кнопкой мыши (или Ctrl+клик)
    -> Открыть -> в окне ещё раз нажмите «Открыть».

  Способ 2:
    Системные настройки -> Конфиденциальность и безопасность
    -> прокрутите вниз, там будет надпись про .command-файл
    -> нажмите «Всё равно открыть».

  Способ 3 (если ничего не помогло):
    Откройте программу «Терминал» (Spotlight: Cmd+Пробел,
    наберите «Терминал») и вставьте туда эту строку,
    затем нажмите Enter:

      bash ~/Downloads/JARVIS/JARVIS-Live.command

    Если папку распаковали в другое место — перетащите
    файл прямо в окно Терминала мышкой, путь подставится
    сам, и нажмите Enter.


--------------------------------------------------------
  ПИШЕТ, ЧТО НЕТ PYTHON
--------------------------------------------------------

Окно само предложит установить инструменты Apple.
Нажмите «Установить», подождите 5-10 минут и снова
дважды кликните по файлу.


--------------------------------------------------------
  КЛЮЧ НЕЙРОСЕТИ
--------------------------------------------------------

JARVIS-Live.command при первом запуске спросит API-ключ
Cloud.ru (foundation-models.api.cloud.ru) — можно вставить
сразу или нажать Enter и ввести его позже в самом
интерфейсе: Настройки → провайдеры. Ключ сохраняется в
~/JARVIS/config.json и переживает все обновления.


--------------------------------------------------------
  ЧТО ДАЛЬШЕ
--------------------------------------------------------

Интерфейс откроется по адресу  http://127.0.0.1:8765
Все данные лежат в папке        ~/JARVIS

Тумблер «AGENT» расположен прямо под кнопкой Send — Джарвис
сам составляет план и выполняет задачу до конца.

Переключатель «Компьютер» — управление вашим Mac
(курсор, клики, ввод текста).

В этой бета-версии облачная генерация картинок пока не включена.
Клиент и безопасный серверный gateway уже подготовлены, но сам
backend будет развёрнут позже. Пользователю не нужно получать
ключ или настраивать внешний сервис.

  ВАЖНО. Без разрешения macOS блокирует управление
  МОЛЧА: клики просто не проходят. Один раз откройте
  Системные настройки -> Конфиденциальность и безопасность:
    • Универсальный доступ -> включить Терминал
    • Запись экрана        -> включить Терминал
  и перезапустите Джарвис.

  Если забыли — Джарвис сам проверит и напишет об этом
  при включении тумблера, а не будет делать вид, что нажал.

Вкладка AUTO слева — фоновые задачи и расписания.

Опасные действия (удаление, оплата, терминал, отправка сообщений)
Джарвис не делает молча — он спросит разрешение в правой панели
«Санкции». Внутри режима «Компьютер» клики, ввод текста и нажатия
клавиш выполняются сразу, без вопросов на каждый шаг: включённый
тумблер — это и есть разрешение.

Кнопка Stop останавливает ВСЮ работу агента — инструменты,
санкции и управление компьютером, а не только текст ответа.


--------------------------------------------------------
  ОСТАНОВИТЬ / УДАЛИТЬ
--------------------------------------------------------

Остановить:  откройте Терминал и введите
                kill $(cat ~/JARVIS/.pid)

Удалить:     остановите, затем удалите папку ~/JARVIS
             и ярлыки с рабочего стола.

Журнал ошибок:  ~/JARVIS/logs/server.log
