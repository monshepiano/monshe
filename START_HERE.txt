JARVIS — файл запуска
=====================

1) Распакуйте этот архив (двойной клик по zip-файлу).

2) Запустите файл запуска:
   macOS   → двойной клик по  start_jarvis.command
   Windows → двойной клик по  start_jarvis.cmd

3) Дальше всё само:
   - спросит ключ DeepSeek (один раз),
   - поставит всё нужное,
   - откроет Джарвиса в браузере.

Ключ DeepSeek берётся на platform.deepseek.com (бесплатно после регистрации).
Без ключа Джарвис запустится в демо-режиме (интерфейс работает, мозг — нет).

Если macOS пишет «неопознанный разработчик»:
   правый клик по файлу → «Открыть» → «Открыть».

Если Windows показывает синий экран SmartScreen:
   «Подробнее» → «Выполнить в любом случае».
