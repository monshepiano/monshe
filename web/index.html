Настройки Джарвиса
Мозг — ключ доступа к моделям
Работает из России без VPN. Получить бесплатно: cloud.ru → Evolution → Foundation Models → создать сервисный аккаунт → API-ключ.
Без него Cloud.ru отвечает «403: Project not found». Где взять: личный кабинет Cloud.ru → раздел Проекты → откройте свой проект → скопируйте ID проекта (длинная строка с дефисами).
Это другой вид ключа: пара логин+пароль из раздела «Учётные данные доступа» → Ключи доступа. Джарвис сам обменяет их на временный токен. Заполняйте, только если обычный API-ключ выдаёт ошибку.
Любой OpenAI-совместимый сервис: VseGPT, AITunnel, ProxyAPI. Подхватится, если основной недоступен.
