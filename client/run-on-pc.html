JARVIS

ЗАПУСК НА ВАШЕМ КОМПЬЮТЕРЕ · 5 ШАГОВ

Зачем это нужно. В облачном превью Джарвис работает в демо-режиме — песочница не выпускает сеть до DeepSeek и Ozon. На вашем компьютере всё заработает по-настоящему: живой «мозг», поиск, камера, покупки, VPN, Telegram.
1

Забрать проект

Скопируйте репозиторий себе на компьютер (или скачайте ZIP на GitHub: кнопка Code → Download ZIP и распакуйте).

# в терминале на вашем ПК:
git clone https://github.com/monshepiano/monshe.git
cd monshe
2

Установить Python и зависимости

Нужен Python 3.10 или новее — с python.org (при установке поставьте галочку Add Python to PATH). Затем в папке проекта:

# Windows (PowerShell) / macOS / Linux
pip install -r requirements.txt

Всё, что нужно для «мозга» и интерфейса, поставится автоматически.

3

Вставить ключ DeepSeek

Скопируйте файл .env.example в новый файл .env (в той же папке) и впишите свой ключ:

DEEPSEEK_API_KEY=sk-...   ← ваш ключ с platform.deepseek.com

Ключ бесплатно выдаётся на platform.deepseek.com после регистрации. Это дёшево и работает из РФ без VPN.

4

Запустить

python run.py

Откройте в браузере: http://localhost:8000

Готово — это тот же интерфейс HUD, но теперь с живым «мозгом».

5

«Руки»: Ozon, VPN, Telegram (по желанию)

Чтобы Джарвис реально управлял компьютером — ставим браузер-автоматизацию и включаем режим ПК:

pip install playwright pyautogui pillow
playwright install chromium
# допишите в .env:
JARVIS_ENABLE_PC=1

Готовые сниппеты (Ozon-корзина, VPN вкл/выкл, сообщение в Telegram) — в файле docs/RUN_ON_PC.md.

?

Частые вопросы

  • Камера не «видит»? У DeepSeek нет зрения. Добавьте в .env ключ GOOGLE_API_KEY=... (Gemini) — и Джарвис начнёт описывать кадры.
  • Покупки безопасны? Джарвис всегда сначала показывает план и ждёт вашего «ОДОБРИТЬ», а оплату на Ozon делаете только вы сами.
  • Хочу сменить «мозг». Меняется в .env (переменные JARVIS_FAST_*, JARVIS_SMART_*, JARVIS_VISION_*) или в «Настройках» интерфейса.
