# JARVIS — персональный AI-агент

Автономный ИИ-агент с интерфейсом в стиле HUD из «Железного человека».
Работает из России без VPN, ставится одним файлом, не требует ни pip, ни npm.

**[→ Как пользоваться](docs/КАК-ПОЛЬЗОВАТЬСЯ.md)** · **[→ Перенос на сервер](docs/СЕРВЕР.md)**

## Установка

Скачайте `install/JARVIS.command` и дважды кликните по нему. Он сам распакует
программу в `~/JARVIS`, пропишет ключи, запустит сервер и откроет браузер.
Повторный запуск = обновление (данные сохраняются).

## Возможности

**БАЗА** — поиск в интернете и чтение страниц, серверная песочница (создание
файлов, Python, shell, архивы), анализ вложений, генерация картинок,
распознавание изображений, видео и голоса.

**AGENT** — переключатель под полем ввода. Агент строит план из нескольких
шагов и выполняет их автономно, без вопросов пользователю.

**AUTO** — фоновая работа: агент сам решает, что унести в фон, ведёт расписания,
уважает тихие часы, шлёт результаты в Telegram. Отдельная вкладка в интерфейсе.

**COMPUTER-USE** — управление курсором, кликами, клавиатурой и приложениями на
Mac пользователя. Реализовано на нативном JXA + CoreGraphics: никаких зависимостей,
есть плавное движение курсора, двойные клики, прокрутка и перетаскивание.

**Безопасность** — трёхуровневая оценка риска инструментов. Опасные действия
(удаление, shell, computer-use, отправка сообщений, оплата) ставятся на паузу
и ждут подтверждения в панели «Санкции»; таймаут 5 минут.

## Оркестрация моделей

Незаметное переключение между уровнями по сложности запроса — дешёвая модель для
простого, дорогая только когда нужно, с автоэскалацией.

| Тир | Назначение | Модель по умолчанию |
|---|---|---|
| nano | короткие реплики | `ai-sage/GigaChat3-10B-A1.8B` |
| base | обычные задачи и поиск | `openai/gpt-oss-120b` |
| smart | сложные рассуждения | крупные MoE (GLM / Qwen3-235B) |
| coder | код и сборка файлов | `Qwen3-Coder-Next` |
| vision | экран, картинки, камера | `Qwen3-VL-8B-Instruct` |
| embed | память и поиск по фактам | `Qwen/Qwen3-Embedding-0.6B` |

Провайдеры: **Cloud.ru Foundation Models** (основной, OpenAI-совместимый API)
и **DeepSeek** (резерв, автопереключение при сбое). Учёт токенов и рублей — в UI.

## Устройство

```
app/jarvis/
  server.py        HTTP + SSE, REST API, статика
  agent.py         агентский цикл, промпты, план, подтверждения
  orchestrator.py  выбор тира, эскалация, сжатие истории
  llm.py           клиент провайдеров: стриминг, tools, vision, embeddings
  auto.py          фоновые задачи, расписания, проактивность, Telegram
  db.py            SQLite: чаты, сообщения, задачи, память, санкции, расходы
  config.py        конфиг в ~/JARVIS/config.json
  tools/           31 инструмент: web, sandbox, computer, media, memory, auto
  web/             интерфейс: HUD, анимации, панели (без сборки)
install/
  build.py         сборка самораспаковывающегося установщика
  template.sh      shell-обёртка установщика
  JARVIS.command   готовый установщик (код внутри, base64)
```

Бэкенд — только стандартная библиотека Python (`http.server`, `urllib`, `sqlite3`).
Фронтенд — статика без бандлера. Пересборка установщика: `python3 install/build.py`.

## Данные

Всё лежит в `~/JARVIS`: `config.json`, `data/` (база), `workspace/` (файлы агента),
`logs/`, `skills/`. Резервная копия — копия этой папки.
