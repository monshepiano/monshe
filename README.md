# J.A.R.V.I.S.

Персональный ИИ-агент с интерфейсом в стиле «Железного человека».
Работает из России без VPN — на моделях Cloud.ru Evolution Foundation Models.

---

## Как запустить (3 шага)

### Шаг 1. Получите ключ (один раз, ~5 минут)

1. Зайдите на **cloud.ru** и зарегистрируйтесь (вход по телефону/Сберу).
2. В личном кабинете: **Пользователи → Сервисные аккаунты → создать аккаунт**.
3. Внутри аккаунта: **Учётные данные доступа → Создать API-ключ**.
   - сервис: **Foundation Models**
   - срок: **1 год**
4. Скопируйте **Key Secret** — он показывается **только один раз**. Сохраните его в заметки.
5. Скопируйте **ID проекта**: раздел **Проекты** → откройте свой проект → *ID проекта*
   (строка вида `50000000-4000-3000-2000-100000000001`).
   Без него Cloud.ru отвечает `403: Project not found`.

### Шаг 2. Запустите

Дважды щёлкните по файлу **`Джарвис.command`**.

- Первый запуск занимает 2–4 минуты — устанавливаются компоненты.
- Браузер откроется сам на `http://localhost:8765`.
- Если macOS скажет «неопознанный разработчик»: правый клик по файлу → **Открыть** → **Открыть**.

### Шаг 3. Вставьте ключ

В открывшемся интерфейсе нажмите **шестерёнку** слева внизу:

- поле **API-ключ Cloud.ru** → вставьте Key Secret;
- поле **ID проекта Cloud.ru** → вставьте ID проекта (обязательно);
- **Проверить ключ** → **Сохранить**.

Всё. Джарвис готов.

## Что он умеет

| | |
|---|---|
| 💬 **Чат** | Обычный разговор, ответы на вопросы, объяснения |
| 🎯 **Агент** | Сам разбивает задачу на шаги и выполняет: ищет, читает сайты, пишет код, собирает файлы |
| 🌐 **Интернет** | Поиск и чтение страниц — всё с его стороны, не с вашего браузера |
| 📎 **Файлы** | Кидайте PDF, Word, Excel, картинки — он прочитает и разберёт |
| 🎙 **Голос** | Кнопка микрофона: говорите, он распознаёт (Whisper) и отвечает |
| 👁 **Камера** | Покажите ему что-нибудь через камеру — опишет и объяснит |
| 🗂 **Песочница** | Создаёт файлы у себя (`~/.jarvis/sandbox`) — скачивайте их из панели «Файлы» |
| 🧠 **Память** | Запоминает факты о вас и учитывает их в ответах |
| ⏱ **Фон** | Задачи по расписанию: «каждое утро — сводка новостей» |
| 🛡 **Безопасность** | Перед опасным действием (терминал, удаление, внешние запросы) спрашивает разрешение |

## Интерфейс

- **Слева** — переключение: Чат / Задачи / Камера / Память.
- **Справа** (кнопка «панель») — три вкладки:
  - **Мысли** — живой терминал: что Джарвис думает и делает прямо сейчас;
  - **Файлы** — всё, что он создал, с кнопкой «Скачать»;
  - **Журнал** — события и его собственные инициативы.
- **Переключатель «Агент»** возле поля ввода: включите, если хотите заставить его работать по шагам.
  Обычно он сам определяет, когда нужен агентский режим.

---

## Настройки (шестерёнка)

- **Ключ Cloud.ru** — главное. Кнопка «Проверить ключ» покажет, сколько моделей доступно.
- **Модели** — какая модель за что отвечает. Кнопка «Загрузить список» покажет доступные вам.
  Значения по умолчанию уже подобраны, менять не обязательно.
- **Персона** — как к вам обращаться и в каком тоне отвечать.
- **Безопасность** — галочки: какие действия требуют вашего подтверждения.
- **Фон** — фоновые задачи и проактивность (Джарвис сам иногда что-то предложит).
- **Telegram** — код готов, но выключен. Понадобится — включите галочку и вставьте токен от @BotFather.
- **Генерация картинок** — ключи FusionBrain (Kandinsky), бесплатно на fusionbrain.ai.

## Обновление

Дважды щёлкните **`Обновить Джарвиса.command`**.
Настройки, память и файлы (`~/.jarvis`) при этом не трогаются.

## Где что лежит

```
~/.jarvis/
├── config.json     настройки и ключи
├── jarvis.db       память, история, задачи
├── sandbox/        файлы, которые создаёт Джарвис
├── uploads/        то, что вы ему прислали
└── skills/         навыки, которым он научился
```

Удалить всё начисто: удалите папку `~/.jarvis`.

## Доступ с телефона (по домашней сети)

Джарвис слушает `0.0.0.0:8765` — значит доступен с любого устройства в вашей Wi-Fi сети.
Узнайте IP Mac (Системные настройки → Wi-Fi → Подробнее) и откройте на телефоне
`http://192.168.x.x:8765`. В Safari: «Поделиться» → «На экран Домой» — получится иконка как у приложения.

> Микрофон и камера в браузере работают только по `https` или на `localhost`.
> На телефоне по http они будут недоступны — это ограничение браузеров, решается при выносе на сервер с доменом.

## Технически

- **Backend:** Python 3.9+, FastAPI, WebSocket, SQLite.
- **Модели:** Cloud.ru Evolution Foundation Models (OpenAI-совместимый API,
  `https://foundation-models.api.cloud.ru/v1`), запасной шлюз настраивается в конфиге.
- **Роутер моделей:** дешёвая модель на простое, сильная — на сложное, отдельные модели
  для кода, зрения и распознавания речи. Переключение незаметно для пользователя.
- **Запуск вручную:** `python -m jarvis.server` (порт из `JARVIS_PORT`, по умолчанию 8765).

```
jarvis/
├── config.py        конфигурация и пути
├── llm.py           слой моделей, роутинг, стриминг, whisper
├── memory.py        SQLite: история, задачи, факты, события, расписания
├── tools.py         16 инструментов агента
├── agent.py         ядро: планирование, цикл шагов, подтверждения
├── scheduler.py     фоновые задачи и проактивность
├── telegram_bot.py  бот (выключен по умолчанию)
└── server.py        FastAPI: WebSocket + REST + статика
web/
├── index.html       HUD-интерфейс
└── assets/          style.css, app.js, иконка, манифест PWA
```
