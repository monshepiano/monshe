# J.A.R.V.I.S. — персональный ИИ-агент

Не чат-бот, а именно **агент**: получает цель, сам разбивает её на шаги, лезет в
интернет, пишет файлы, работает в браузере, рисует картинки, смотрит через камеру,
пишет вам в телеграм и спрашивает разрешения перед всем опасным.

Работает **в России без VPN** — мозг по умолчанию GigaChat (Foundation Models Сбера).
Бесплатно: у GigaChat есть постоянный бесплатный лимит для физлиц.

---

## Как запустить (3 шага, кодить не нужно)

### Шаг 1. Откройте файл запуска

| Ваш компьютер | Что открыть двойным кликом |
|---|---|
| **macOS** | `Джарвис.command` |
| **Windows** | `Джарвис.bat` |
| **Linux** | `Джарвис.command` |

Откроется чёрное окошко с текстом — это нормально, **закрывать его нельзя**, пока
Джарвис работает. В первый раз он сам поставит всё нужное (1–3 минуты), потом
запускается за пару секунд.

> **macOS ругается «неопознанный разработчик»?**
> Правый клик по `Джарвис.command` → «Открыть» → в окошке ещё раз «Открыть».
> Достаточно сделать один раз.

Браузер откроется сам на `http://localhost:8765`.

### Шаг 2. Вставьте бесплатный ключ

1. Зайдите на **developers.sber.ru** → раздел **GigaChat API** → кнопка «Получить API-ключ».
2. Войдите по Сбер ID, создайте проект **«Для физических лиц»**.
3. Скопируйте длинную строку **Authorization key** (выглядит как `ZDk4M...==`).
4. В Джарвисе нажмите шестерёнку ⚙ справа сверху → вкладка **Модели** →
   вставьте ключ в первое поле → **Сохранить**.

Индикатор в шапке загорится зелёным — Джарвис в сети.

### Шаг 3. Подключите телеграм (по желанию, 2 минуты)

Чтобы Джарвис писал вам о выполненных задачах, даже когда окно закрыто:

1. В телеграме напишите **@BotFather** → команда `/newbot` → придумайте имя.
2. Скопируйте выданный токен → ⚙ → вкладка **Телеграм** → первое поле.
3. Напишите **@userinfobot** — он пришлёт ваш номер (chat_id) → второе поле.
4. Откройте своего бота и нажмите **«Старт»** (иначе он не сможет вам писать).
5. Кнопка **«Проверить связь»** — должно прийти сообщение.

Дальше можно командовать прямо из телеграма:
`/task собери сводку новостей по ИИ` · `/status` · `/yes` · `/no`.

## Что он умеет

**Отвечает на вопросы с актуальными данными** — ищет в интернете и читает страницы,
а не выдумывает из головы.

**Выполняет задачи в фоне.** Скажите «собери сводку новостей по электромобилям и
пришли в телеграм» — Джарвис составит план из шагов, выполнит их сам и напишет,
когда будет готово. Окно можно закрыть, он продолжит.

**Работает по расписанию.** «Каждое утро присылай прогноз погоды» — панель
«Задачи» слева, расписание: разово / ежечасно / ежедневно / еженедельно / каждые N минут.

**Делает файлы.** У него своя песочница: пишет тексты, таблицы, код, собирает
архивы, а потом присылает файл вам в телеграм. Всё лежит в папке `~/.jarvis/workspace`.

**Работает в браузере не на вашем компьютере.** Отдельный невидимый браузер внутри
Джарвиса: открывает сайты, кликает, заполняет формы, читает содержимое. Ваши вкладки
и пароли он не трогает.

**Видит.** Кнопка камеры 📷 — покажите картину на стене, товар, документ, и спросите,
что это. Понимает и прикреплённые файлы (скрепка 📎).

**Слышит.** Кнопка микрофона 🎤 — говорите, он распознает речь и ответит.
(Работает в Chrome и Safari.)

**Рисует.** «Нарисуй закат над Москва-Сити в стиле киберпанк» — картинка появится
в песочнице и в чате.

**Помнит вас.** Панель «Память»: имя, город, привычки, предпочтения. Со временем
подстраивается и напоминает сам, если включён проактивный режим.

**Переключает модели незаметно.** Простой вопрос → быстрая дешёвая модель,
сложный анализ → GigaChat-Max. Вы этого не замечаете, вы просто платите меньше.

## Безопасность

Перед всем, что может навредить — покупка, оплата, удаление файлов, команда в
системе, отправка данных наружу — Джарвис **останавливается и спрашивает**.
Панель уведомлений выезжает сама, с кнопками «Разрешить» / «Отклонить».
Если вы не у компьютера, тот же вопрос придёт в телеграм — отвечаете `/yes` или `/no`.

Отключить подтверждения можно в ⚙ → «Безопасность», но лучше не надо.

Все ключи хранятся только на вашем компьютере, в файле `~/.jarvis/config.json`.
Никуда больше они не уходят.

## Как открыть с телефона

Пока Джарвис запущен на компьютере:

1. Узнайте IP компьютера в домашней сети (macOS: Системные настройки → Wi-Fi →
   Подробнее; Windows: команда `ipconfig`). Будет вида `192.168.1.50`.
2. На телефоне в браузере откройте `http://192.168.1.50:8765`.
3. Safari: «Поделиться» → **«На экран Домой»**. Появится иконка как у обычного
   приложения, откроется на весь экран без адресной строки. Это и есть
   приложение для iOS — устанавливать ничего не нужно.

**Важно:** если открываете Джарвиса из интернета, а не только дома —
обязательно задайте пароль в ⚙ → «Сервер» → «Токен доступа».

## Как поставить на сервер (чтобы работал круглосуточно)

Подойдёт любой российский VPS за ~200 ₽/месяц (Timeweb, Selectel, Reg.ru).
Возьмите Ubuntu 22.04 и выполните по SSH:

```bash
sudo apt update && sudo apt install -y python3 python3-venv git
git clone <адрес-этого-репозитория> jarvis && cd jarvis
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
.venv/bin/python run.py
```

Чтобы работал постоянно и сам поднимался после перезагрузки:

```bash
sudo tee /etc/systemd/system/jarvis.service >/dev/null <<'EOF'
[Unit]
Description=Jarvis
After=network.target

[Service]
User=root
WorkingDirectory=/root/jarvis
Environment=JARVIS_NO_BROWSER=1
ExecStart=/root/jarvis/.venv/bin/python /root/jarvis/run.py
Restart=always

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now jarvis
```

Затем откройте `http://<ip-сервера>:8765` и **сразу задайте токен доступа**
в ⚙ → «Сервер».

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| «Не подключена ни одна модель» | Вставьте ключ GigaChat в ⚙ → Модели |
| Ошибка сертификата / SSL при обращении к Сберу | Так и задумано: ⚙ проверка сертификата отключена по умолчанию. Если ошибка осталась — установите сертификат НУЦ Минцифры с сайта госуслуг |
| Джарвис не открывает сайты сам | Браузерный движок не установлен. Удалите файл `.jarvis-installed` и запустите `Джарвис.command` заново, ответьте `y` |
| Не работает микрофон | Нужен Chrome или Safari; разрешите доступ к микрофону в браузере |
| Порт занят | ⚙ → Сервер → смените порт → перезапустите |
| Хочу начать с чистого листа | Удалите папку `~/.jarvis` (в ней все настройки, история и файлы) |

## Что внутри (для любопытных)

```
backend/app/
  main.py        — веб-сервер: API, живой поток событий, раздача интерфейса
  agent.py       — ядро: цикл «подумал → вызвал инструмент → посмотрел результат»
  router.py      — выбор модели под сложность задачи
  scheduler.py   — фоновые задачи, расписание, проактивность, телеграм
  store.py       — база SQLite: чаты, задачи, память, уведомления
  config.py      — настройки в ~/.jarvis/config.json
  providers/     — GigaChat и любые OpenAI-совместимые модели
  tools/         — поиск, браузер, песочница, телеграм
frontend/src/    — интерфейс: React + свой HUD-стиль
run.py           — запуск
```

Порядок выбора мозга: **GigaChat** → локальная **Ollama** (если установлена) →
**OpenRouter** → любой свой сервер. Первый доступный и работает.
