# JARVIS — личный ИИ-ассистент

Свой «Джарвис» в духе Железного человека: слышит голос, видит камерой,
сам выбирает «мозг» по сложности задачи и умеет действовать — искать в сети,
открывать Ozon, управлять компьютером (VPN, Telegram) — но **только с вашего
подтверждения**.

## Что внутри

| Модуль | Файл | Роль |
|---|---|---|
| Роутер «мозга» | `server/brain.py` | выбирает движок по сложности (fast / smart / vision) |
| Провайдеры | `server/providers.py` | DeepSeek, OpenAI, Anthropic, Gemini, Ollama — чистый HTTP |
| Инструменты | `server/tools.py` | поиск, чтение страниц, покупка, управление ПК + санкции |
| API | `server/app.py` | FastAPI: чат, санкции, настройки |
| Интерфейс | `client/` | HUD в стиле Iron Man (HTML/CSS/JS, без сборщиков) |

## Быстрый старт (эта песочница)

```bash
pip install -r requirements.txt
python run.py            # http://localhost:8000
```

Без API-ключей работает **демо-режим** (имитация мозга), чтобы потрогать
интерфейс, голос, камеру и поток подтверждений. Чтобы мозг стал настоящим —
вставьте ключ DeepSeek в «Настройки» (⚙) или в `.env`.

## Как работает «мозг-роутер»

Джарвис сам решает, чем думать, чтобы экономить:

- **fast** — простые реплики → `deepseek-chat` (копейки);
- **smart** — сложные/агентные задачи, «купи/сравни/разбери» → `deepseek-reasoner`;
- **vision** — пришёл кадр с камеры → vision-модель (Gemini / GPT-4o; у DeepSeek зрения пока нет).

Движки меняются на лету — в `.env` (переменные `JARVIS_*`) или в интерфейсе.
DeepSeek выбран по умолчанию: дёшево и работает из РФ без VPN.

## Безопасность (санкции)

Покупки, оплата, сообщения, VPN и любые изменения **не выполняются сразу**:
инструмент формирует план, а вы одобряете его кнопкой в панели «САНКЦИИ».
Финальную оплату Джарвис по дизайну никогда не делает сам.

## Запуск на своём ПК (реальные «руки»)

Управление вашим компьютером (клики, VPN, Telegram, Ozon) работает только
локально. Полная инструкция — [docs/RUN_ON_PC.md](docs/RUN_ON_PC.md).

## Чего НЕ умеет

- Покупать и платить полностью сам — по соображениям безопасности (капча, оплата, карта).
- Видеть, пока не задана vision-модель.
