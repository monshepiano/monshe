# Перенос Джарвиса на сервер

Когда наигрались на MacBook и хотите заходить с телефона и других устройств.
Подойдёт любая недорогая VPS в России (Timeweb, Selectel, Reg.ru, Cloud.ru) —
хватит 1 ядра и 1 ГБ памяти. Нужен только Python 3.8+, никаких зависимостей.

## 1. Загрузить и запустить

```bash
# на своём Mac: закинуть установщик на сервер
scp JARVIS.command root@ВАШ_IP:/root/

# на сервере
ssh root@ВАШ_IP
bash /root/JARVIS.command      # распакует в ~/JARVIS и запустит
```

Чтобы Джарвис слушал не только localhost:

```bash
kill $(cat ~/JARVIS/.pid)
cd ~/JARVIS/app
JARVIS_HOST=0.0.0.0 JARVIS_PORT=8765 JARVIS_NO_BROWSER=1 python3 -m jarvis
```

## 2. Автозапуск (systemd)

```bash
cat > /etc/systemd/system/jarvis.service <<'EOF'
[Unit]
Description=JARVIS AI agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/JARVIS/app
Environment=JARVIS_HOST=127.0.0.1
Environment=JARVIS_PORT=8765
Environment=JARVIS_NO_BROWSER=1
ExecStart=/usr/bin/python3 -m jarvis
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now jarvis
systemctl status jarvis
```

## 3. Домен, HTTPS и пароль

Открывать порт 8765 наружу без защиты нельзя — у агента есть доступ к терминалу.
Ставим Nginx с паролем и сертификатом.

```bash
apt update && apt install -y nginx apache2-utils certbot python3-certbot-nginx
htpasswd -c /etc/nginx/.jarvis ваше_имя      # придумает пароль

cat > /etc/nginx/sites-available/jarvis <<'EOF'
server {
    listen 80;
    server_name jarvis.ваш-домен.ру;

    location / {
        auth_basic "JARVIS";
        auth_basic_user_file /etc/nginx/.jarvis;

        proxy_pass http://127.0.0.1:8765;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;

        # важно для потоковых ответов (SSE)
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
        chunked_transfer_encoding on;
    }
    client_max_body_size 64m;
}
EOF

ln -sf /etc/nginx/sites-available/jarvis /etc/nginx/sites-enabled/jarvis
nginx -t && systemctl reload nginx
certbot --nginx -d jarvis.ваш-домен.ру
```

Теперь `https://jarvis.ваш-домен.ру` открывается с любого устройства, включая телефон.
Интерфейс адаптивный.

## 4. Что меняется на сервере

- **Computer-use выключается сам** — управлять мышью можно только на macOS,
  где Джарвис запущен рядом с вами. На сервере остаются интернет, песочница,
  файлы, медиа, память, AUTO.
- **Фоновые задачи работают лучше** — сервер не засыпает вместе с ноутбуком,
  расписания срабатывают всегда.
- **Telegram-уведомления особенно полезны** — настройте их в разделе Настройки.

Удобная схема: сервер держит AUTO и общий доступ, а на MacBook остаётся
локальная копия для управления компьютером.

## 5. Обслуживание

```bash
journalctl -u jarvis -f          # смотреть логи
systemctl restart jarvis         # перезапуск
tail -50 ~/JARVIS/logs/server.log
```

Резервная копия — это просто папка `~/JARVIS` (там чаты, память, файлы, настройки):

```bash
tar -czf jarvis-backup.tgz ~/JARVIS
```

Обновление — снова запустить свежий `JARVIS.command`: он заменит код в
`~/JARVIS/app` и не тронет данные.
